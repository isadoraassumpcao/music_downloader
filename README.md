# Music Downloader from Youtube
## What it does:
I created this project alongside chatgpt to help me manage my downloaded songs.

## How it works:
Write name + artist of the songs -> yt-dlp searches the songs -> ffmpeg converts them into mp3 -> the downloaded songs are added directly on a separate folder on my desktop

## Why I created this:
I love listening to songs, but hate paying subscriptions. By downloading the songs I like on my phone, I carry them whenever I go, but, since I like lots of songs and downloading one by one
takes a lot of time, I had to simplify the process of downloading them :)

## Requirements :
Python, FFmpeg, and Node.js.

Install dependencies: pip install -r requirements.txt
Install FFmpeg and add it to your system PATH.
Install Node.js and ensure yt-dlp can access it.
